# Loftone

Tu biblioteca musical personal: importa tu música, organízala en listas,
escúchala en local o en streaming desde tu NAS.

## Getting Started

Proyecto Flutter. Para ejecutarlo en escritorio:

```sh
flutter pub get
flutter run -d windows
```

Para compilar los iconos de la aplicación (Windows y macOS) a partir del
logo, ejecuta en la raíz del proyecto:

```sh
dart run tool/generate_app_icons.dart
```
